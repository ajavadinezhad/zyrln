# ساخت رله شخصی

[بازگشت به راهنمای برنامه](guide.md) · [English](../relay-setup.md)

اگر کانفیگ آماده دارید، به این مراحل نیازی ندارید. برای ساخت رله، یک حساب گوگل و یکی از این دو خروجی را لازم دارید: Cloudflare Worker یا VPS لینوکسی. برای ساخت کانفیگ اندروید لازم نیست برنامه دسکتاپ زیرلن را نصب کنید.

ترتیب کار: **انتخاب خروجی ← راه‌اندازی خروجی ← انتشار پل گوگل ← ساخت کانفیگ برنامه**.

## ۱. دو کلید جداگانه بسازید

با یک برنامه مدیریت رمز، دو رمز طولانی و تصادفی بسازید: **کلید برنامه** و **کلید خروجی**. هر دو را خصوصی نگه دارید.

| مقدار | محل استفاده |
|---|---|
| کلید برنامه | قسمت کلید در برنامه و `AUTH_KEY` در Apps Script |
| کلید خروجی | `EXIT_RELAY_KEY` در Apps Script و `ZYRLN_RELAY_KEY` روی خروجی |

برنامه به کلید خروجی نیاز ندارد. در مرحله ۲ **آدرس خروجی** و در مرحله ۳ **آدرس Apps Script** را می‌گیرید؛ این دو آدرس متفاوت‌اند.

## ۲. یک خروجی راه‌اندازی کنید

### Cloudflare Worker

[راهنمای Cloudflare](cloudflare-setup.md) را انجام دهید، سپس با آدرس Worker و کلید خروجی به مرحله ۳ برگردید.

تونل TCP کلادفلر به مقصدهایی روی محدوده IP خود Cloudflare وصل نمی‌شود. اگر این مقصدها را نیاز دارید، VPS انتخاب کنید. دسترسی و محدودیت مصرف به حساب کلادفلر شما بستگی دارد.

### VPS لینوکسی

سرور لینوکسی amd64 یا arm64، دسترسی SSH و کاربر root یا دارای sudo لازم است. این مراحل را از دستگاهی با Bash، SSH و SCP انجام دهید؛ در ویندوز می‌توانید از WSL یا Git Bash استفاده کنید.

1. فایل `zyrln-VERSION-vps.zip` را از [انتشارها](https://github.com/ajavadinezhad/zyrln/releases) بگیرید و از حالت فشرده خارج کنید.
2. در پوشه استخراج‌شده ترمینال باز کنید. کلید خروجی و مشخصات SSH سرورتان را جایگزین کنید:

   ```bash
   chmod +x install-vps-relay.sh
   ZYRLN_RELAY_KEY='YOUR_EXIT_KEY' ./install-vps-relay.sh user@YOUR_VPS_IP
   ```

3. پورت TCP شماره `8787` را در فایروال ارائه‌دهنده VPS باز کنید. نصب‌کننده در صورت وجود UFW تلاش می‌کند آن را هم تنظیم کند.
4. بررسی کنید:

   ```bash
   curl http://YOUR_VPS_IP:8787/healthz
   ```

   پاسخ مورد انتظار `ok` است. این فقط در دسترس بودن سرور را نشان می‌دهد، نه کار کردن کل زنجیره گوگل.

کلید خروجی را نگه دارید. آدرس رله `http://YOUR_VPS_IP:8787/relay` و آدرس تونل `http://YOUR_VPS_IP:8787/tunnel` است.

این آدرس‌های نمونه HTTP هستند و مسیر گوگل تا VPS، از جمله کلید خروجی، در این حالت TLS ندارد. برای محافظت این بخش از مسیر، یک reverse proxy با HTTPS راه‌اندازی کنید و هر دو آدرس را مطابق آن تغییر دهید.

## ۳. پل Google Apps Script را منتشر کنید

1. در [Google Apps Script](https://script.google.com) یک **New project** بسازید.
2. تمام محتوای [Code.gs](../../relay/deploy/apps-script/Code.gs) را جایگزین متن ویرایشگر کنید.
3. چهار مقدار ابتدای فایل را با **یکی** از نمونه‌های زیر تنظیم کنید. باقی فایل را نگه دارید.

**برای Cloudflare:**

```js
const AUTH_KEY = "YOUR_APP_KEY";
const EXIT_RELAY_URL = "https://YOUR_WORKER.YOUR_SUBDOMAIN.workers.dev";
const EXIT_TUNNEL_URL = "";
const EXIT_RELAY_KEY = "YOUR_EXIT_KEY";
```

آدرس پایه Worker را بدون `/relay` وارد کنید. خالی بودن آدرس تونل باعث می‌شود اسکریپت مسیر `/tunnel` را خودش بسازد.

**برای VPS:**

```js
const AUTH_KEY = "YOUR_APP_KEY";
const EXIT_RELAY_URL = "http://YOUR_VPS_IP:8787/relay";
const EXIT_TUNNEL_URL = "http://YOUR_VPS_IP:8787/tunnel";
const EXIT_RELAY_KEY = "YOUR_EXIT_KEY";
```

4. مسیر **Deploy → New deployment → Web app** را باز کنید. **Execute as: Me** و **Who has access: Anyone** را انتخاب کنید. مجوزهای گوگل را برای پروژه خودتان بررسی و تأیید کنید. اگر حساب شما گزینه دسترسی عمومی ندارد، با این تنظیمات قابل استفاده نیست؛ با مدیر حسابتان بررسی کنید.
5. منتشر کنید و آدرس وب‌اپ با انتهای `/exec` را بردارید.

**بعد از تغییر اسکریپت منتشرشده:** به **Deploy → Manage deployments → Edit (مداد) → New version → Deploy** بروید. ذخیره متن در ویرایشگر به‌تنهایی نسخه منتشرشده را تغییر نمی‌دهد.

## ۴. کانفیگ برنامه را بسازید

در این قالب، **آدرس Apps Script** و **کلید برنامه** را جایگزین کنید:

```json
{"url":"https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec","key":"YOUR_APP_KEY"}
```

تمام JSON را کپی کنید و [مراحل اندروید](guide.md#اندروید) را انجام دهید؛ در دسکتاپ می‌توانید دو مقدار را دستی وارد کنید. آدرس Worker یا VPS و کلید خروجی را در کانفیگ برنامه نگذارید.

## بررسی قبل از اشتراک‌گذاری

1. دسترسی Apps Script روی **Anyone** باشد و آخرین نسخه را دیپلوی کرده باشید.
2. کلید برنامه با `AUTH_KEY` یکی باشد.
3. کلید خروجی در Apps Script و Worker یا VPS یکسان باشد.
4. زیرلن را وصل کنید و یک سایت باز کنید؛ Ping به‌تنهایی کافی نیست.
5. فقط کانفیگ برنامه را خصوصی به اشتراک بگذارید، نه کلید خروجی یا اطلاعات ورود حساب گوگل.

سهمیه درخواست‌های گوگل بین اسکریپت‌های متعلق به یک حساب مشترک است. ساخت دیپلوی بیشتر روی همان حساب سهمیه جدید نمی‌دهد. حتی با تنظیم درست، محدودیت سهمیه یا اختلال سرویس می‌تواند روی اتصال اثر بگذارد.
