# راهنمای زیرلن

[<span dir="ltr">English</span>](../../README.md) · [دانلود](https://github.com/ajavadinezhad/zyrln/releases)

زیرلن برای دسترسی به سایت‌های مسدودشده از مسیر گوگل استفاده می‌کند. می‌توانید کانفیگ یک فرد مورد اعتماد را بگیرید، یا با یک حساب گوگل و خروجی <span dir="ltr">Cloudflare</span> یا سرور <span dir="ltr">VPS</span> اتصال خودتان را بسازید. نتیجه به شرایط شبکه شما بستگی دارد.

## از کجا شروع کنم؟

| وضعیت شما | مسیر مناسب |
|---|---|
| از یک فرد مورد اعتماد کانفیگ گرفته‌اید | برنامه را نصب کنید و [وصل شوید](#اتصال-با-کانفیگ) |
| کانفیگ ندارید و می‌خواهید رله خودتان را بسازید | [ساخت رله شخصی](relay-setup.md) را دنبال کنید و بعد به این صفحه برگردید |
| فقط اتصال مستقیم به سرویس‌های گوگل را می‌خواهید | [حالت مستقیم](#حالت-مستقیم-بدون-کانفیگ) را امتحان کنید |

کانفیگ شامل **آدرس <span dir="ltr">Google Apps Script</span>** با انتهای <code dir="ltr">/exec</code> و **کلید برنامه** است. آدرس <span dir="ltr">VPS</span> یا <span dir="ltr">Worker</span> را در قسمت آدرس رله برنامه وارد نکنید. کانفیگ را خصوصی نگه دارید؛ هر کسی که آن را داشته باشد می‌تواند از رله و سهمیه‌اش استفاده کند.

## کدام فایل را دانلود کنم؟

در [صفحه انتشارها](https://github.com/ajavadinezhad/zyrln/releases)، نسخه موردنظر را باز کنید و فایل را از بخش **<span dir="ltr">Assets</span>** بگیرید.

| دستگاه | انتهای نام فایل |
|---|---|
| اندروید ۹ به بالا، در پیش‌نمایش ۲.۱ | <code dir="ltr">-android.apk</code> |
| ویندوز | <code dir="ltr">-windows-amd64.exe</code> |
| لینوکس با پردازنده ۶۴ بیتی <span dir="ltr">Intel/AMD</span> | <code dir="ltr">-linux-amd64</code> |
| مک با پردازنده <span dir="ltr">Apple Silicon</span> | <code dir="ltr">-darwin-arm64</code> |
| مک با پردازنده <span dir="ltr">Intel</span> | <code dir="ltr">-darwin-amd64</code> |

فایل <code dir="ltr">-vps.zip</code> برای صاحب سرور است؛ برای استفاده از کانفیگ آماده به آن نیاز ندارید. فایل‌های **<span dir="ltr">Source code</span>** هم برنامه قابل نصب نیستند.

**ارتقای اندروید از نسخه <code dir="ltr">v2.0</code> به نسخه <code dir="ltr">v2.1-pre-1</code>:** اول از کانفیگ‌ها خروجی بگیرید. کلید امضای برنامه عوض شده و باید نسخه قبلی را حذف کنید، سپس پیش‌نمایش را نصب و کانفیگ‌ها را وارد کنید. حذف برنامه اطلاعات آن را پاک می‌کند.

## اتصال با کانفیگ

### اندروید

به کامپیوتر، تنظیم پروکسی مرورگر یا نصب گواهی <span dir="ltr">CA</span> نیاز ندارید.

1. فایل <span dir="ltr">APK</span> اندروید را نصب کنید.
2. تمام متن کانفیگ را از <code dir="ltr">{</code> تا <code dir="ltr">}</code> کپی کنید.
3. زیرلن را باز کنید و **وارد کردن (<span dir="ltr">Import</span>)** را بزنید. اگر آدرس و کلید را جداگانه دارید، با **+** آن‌ها را وارد کنید.
4. پروفایل واردشده را انتخاب کنید، **اتصال (<span dir="ltr">Connect</span>)** را بزنید و مجوز <span dir="ltr">VPN</span> اندروید را تأیید کنید.
5. یک سایت را در مرورگر باز کنید. موفق بودن <span dir="ltr">Ping</span> به‌تنهایی به معنی کار کردن مرور وب نیست.

اختیاری: برای تغییر **تونل تفکیک‌شده (<span dir="ltr">Split tunnel</span>)** اول اتصال را قطع کنید، سپس برنامه‌هایی را که باید از زیرلن عبور کنند انتخاب کنید. برای فرستادن کانفیگ به فرد مورد اعتماد، از گزینه اشتراک‌گذاری یا خروجی پروفایل استفاده کنید.

### ویندوز، لینوکس و مک

رابط دسکتاپ در مرورگر باز می‌شود و یک پروکسی محلی را کنترل می‌کند. باز شدن این صفحه به‌تنهایی ترافیک مرورگر را از زیرلن عبور نمی‌دهد.

1. در ویندوز فایل <code dir="ltr">.exe</code> را اجرا کنید. در لینوکس و مک، نام فایل دانلودشده را در دستورهای زیر جایگزین کنید:

   <div dir="ltr">

   ```bash
   chmod +x ./YOUR_DOWNLOADED_FILE
   ./YOUR_DOWNLOADED_FILE -gui
   ```

   </div>

2. با **+** پروفایل بسازید، آدرس <span dir="ltr">Apps Script</span> و کلید برنامه را وارد کنید، سپس ذخیره و انتخاب کنید.
3. در **<span dir="ltr">Tools → Security</span>** گواهی <span dir="ltr">CA</span> زیرلن را بسازید و دانلود کنید؛ این فایل برای مورد اعتماد قرار دادن اتصال رله در مرورگر لازم است. آن را در مرورگری که برای زیرلن استفاده می‌کنید، به‌عنوان مرجع مورد اعتماد سایت‌ها وارد کنید. در فایرفاکس: **<span dir="ltr">Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import</span>**. محل تنظیم گواهی در <span dir="ltr">Chrome</span> و <span dir="ltr">Edge</span> به سیستم‌عامل بستگی دارد؛ از بخش مدیریت گواهی مرورگر استفاده کنید. فقط گواهی ساخته‌شده توسط زیرلن خودتان را مورد اعتماد قرار دهید.
4. پروکسی **<span dir="ltr">HTTP</span>** مرورگر را روی آدرس <code dir="ltr">127.0.0.1</code> و پورت <code dir="ltr">8085</code> بگذارید. در فایرفاکس استفاده از همین پروکسی برای <span dir="ltr">HTTPS</span> را هم فعال کنید. <span dir="ltr">Chrome</span> و <span dir="ltr">Edge</span> معمولاً از تنظیم پروکسی سیستم‌عامل استفاده می‌کنند و ممکن است برنامه‌های دیگر هم تحت تأثیر قرار بگیرند. پروکسی <span dir="ltr">SOCKS5</span> هم روی <code dir="ltr">127.0.0.1:1080</code> در دسترس است.
5. **<span dir="ltr">Connect</span>** را بزنید و یک سایت را در همان مرورگر باز کنید.

بعد از پایان کار، اتصال را قطع و تنظیم پروکسی مرورگر یا سیستم را خاموش کنید تا مرورگر به پروکسی متوقف‌شده وصل نماند.

برای انتقال کانفیگ به اندروید از **<span dir="ltr">Tools → Mobile Export</span>** استفاده کنید و متن کامل را خصوصی بفرستید.

## حالت مستقیم بدون کانفیگ

این حالت برای سرویس‌های گوگل است و جای رله برای سایت‌های دیگر را نمی‌گیرد. ممکن است برای بعضی محدودیت‌ها کمک کند، اما از همه نوع مسدودسازی عبور نمی‌کند.

- **اندروید:** ورودی <span dir="ltr">Direct/Google</span> را انتخاب کنید، اتصال را بزنید و مجوز <span dir="ltr">VPN</span> را بدهید.
- **دسکتاپ:** گزینه **<span dir="ltr">Direct (Google)</span>** را انتخاب کنید، وصل شوید و پروکسی مرورگر را طبق مراحل بالا تنظیم کنید. برای حالت مستقیم به گواهی <span dir="ltr">CA</span> زیرلن نیاز ندارید.

## اگر وصل نشد

| مشکل | قدم بعدی |
|---|---|
| کانفیگ وارد نمی‌شود | تمام <span dir="ltr">JSON</span> را کپی کنید؛ باید دو قسمت <code dir="ltr">url</code> و <code dir="ltr">key</code> داشته باشد. |
| خطای <span dir="ltr">Unauthorized</span> یا کلید اشتباه | صاحب کانفیگ باید کلید برنامه را با <code dir="ltr">AUTH_KEY</code> در <span dir="ltr">Apps Script</span> تطبیق دهد. |
| دسکتاپ وصل است ولی سایت باز نمی‌شود | تنظیم پروکسی و گواهی مرورگر را بررسی کنید. |
| بعضی سایت‌ها با <span dir="ltr">Cloudflare</span> باز نمی‌شوند | تونل <span dir="ltr">TCP</span> کلادفلر نمی‌تواند به محدوده <span dir="ltr">IP</span> خود <span dir="ltr">Cloudflare</span> وصل شود. پروفایل <span dir="ltr">VPS</span> را امتحان کنید؛ این محدودیت به‌خصوص روی مسیر تونل اندروید اثر دارد. |
| سهمیه گوگل تمام شده | پروفایلی از یک حساب گوگل دیگر را امتحان کنید یا منتظر بازیابی سهمیه بمانید. دیپلوی‌های یک حساب سهمیه مشترک دارند. |
| پاسخ <span dir="ltr">HTML</span> به‌جای <span dir="ltr">JSON</span> یا رله در دسترس نیست | صاحب رله باید دسترسی دیپلوی، نسخه منتشرشده و خطاهای سهمیه را بررسی کند. <span dir="ltr">HTML</span> به‌تنهایی به معنی تمام شدن سهمیه نیست. |
| اندروید دوباره مجوز <span dir="ltr">VPN</span> می‌خواهد | مجوز را بدهید؛ ممکن است <span dir="ltr">VPN</span> دیگری جای زیرلن را گرفته باشد. |

اگر صاحب رله هستید، [فهرست بررسی راه‌اندازی](relay-setup.md#بررسی-قبل-از-اشتراکگذاری) را ببینید؛ در غیر این صورت از صاحب کانفیگ بخواهید رله را بررسی کند. برای [گزارش مشکل](https://github.com/ajavadinezhad/zyrln/issues)، مدل دستگاه، نسخه برنامه، نوع خروجی، متن خطا و مراحل تکرار مشکل را بنویسید. کلیدها و کانفیگ خصوصی را از گزارش حذف کنید.
