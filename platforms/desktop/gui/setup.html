1. Choose your relay

Set up Cloudflare

You’ll need a Cloudflare account and Node.js with npm.

Find your Workers subdomain in the Cloudflare dashboard. Replace “your-subdomain” below with it. Choose a new Worker name if you already use zyrln-exit.

Unzip the download and open a terminal in that folder. Run these commands one at a time. When the second command asks for a secret, click Copy exit key and paste it into the terminal. If asked, create the new Worker.

npx wrangler login
npx wrangler secret put ZYRLN_RELAY_KEY
npx wrangler deploy

Make sure Wrangler shows the hostname you entered and the TUNNEL_HUB binding.

Use your VPS

Use the public address Google can reach, ending in /relay. For a new install you can leave this blank to use your SSH host and port 8787. HTTPS is recommended; with HTTP the exit key travels without encryption.

  1. Download the VPS ZIP from Releases, unzip it, and open a Bash terminal in that folder. On Windows use WSL or Git Bash.
  2. Paste the command below into that terminal. When asked for the exit key, use the copy button and paste it. Your SSH user needs root or sudo access.
  3. Allow incoming TCP port 8787 in the VPS provider’s firewall. If you use HTTPS, forward both relay and tunnel paths through the same proxy.
