# راهنمای زیرلن

[English](../../README.md) · [دانلود](https://github.com/ajavadinezhad/zyrln/releases)

زیرلن برای دسترسی به سایت‌های مسدودشده از مسیر گوگل استفاده می‌کند. می‌توانید کانفیگ یک فرد مورد اعتماد را بگیرید، یا با یک حساب گوگل و خروجی Cloudflare یا سرور VPS اتصال خودتان را بسازید. نتیجه به شرایط شبکه شما بستگی دارد.

## از کجا شروع کنم؟

| وضعیت شما | مسیر مناسب |
|---|---|
| از یک فرد مورد اعتماد کانفیگ گرفته‌اید | برنامه را نصب کنید و [وصل شوید](#اتصال-با-کانفیگ) |
| کانفیگ ندارید و می‌خواهید رله خودتان را بسازید | [ساخت رله شخصی](relay-setup.md) را دنبال کنید و بعد به این صفحه برگردید |
| فقط اتصال مستقیم به سرویس‌های گوگل را می‌خواهید | [حالت مستقیم](#حالت-مستقیم-بدون-کانفیگ) را امتحان کنید |

کانفیگ شامل **آدرس Google Apps Script** با انتهای `/exec` و **کلید برنامه** است. آدرس VPS یا Worker را در قسمت آدرس رله برنامه وارد نکنید. کانفیگ را خصوصی نگه دارید؛ هر کسی که آن را داشته باشد می‌تواند از رله و سهمیه‌اش استفاده کند.

## کدام فایل را دانلود کنم؟

در [صفحه انتشارها](https://github.com/ajavadinezhad/zyrln/releases)، نسخه موردنظر را باز کنید و فایل را از بخش **Assets** بگیرید.

| دستگاه | انتهای نام فایل |
|---|---|
| اندروید ۹ به بالا، در پیش‌نمایش ۲.۱ | `-android.apk` |
| ویندوز | `-windows-amd64.exe` |
| لینوکس با پردازنده ۶۴ بیتی Intel/AMD | `-linux-amd64` |
| مک با پردازنده Apple Silicon | `-darwin-arm64` |
| مک با پردازنده Intel | `-darwin-amd64` |

فایل `-vps.zip` برای صاحب سرور است؛ برای استفاده از کانفیگ آماده به آن نیاز ندارید. فایل‌های **Source code** هم برنامه قابل نصب نیستند.

**ارتقا از اندروید v2.0 به v2.1-pre-1:** اول از کانفیگ‌ها خروجی بگیرید. کلید امضای برنامه عوض شده و باید نسخه قبلی را حذف کنید، سپس پیش‌نمایش را نصب و کانفیگ‌ها را وارد کنید. حذف برنامه اطلاعات آن را پاک می‌کند.

## اتصال با کانفیگ

### اندروید

به کامپیوتر، تنظیم پروکسی مرورگر یا نصب گواهی CA نیاز ندارید.

1. فایل APK اندروید را نصب کنید.
2. تمام متن کانفیگ را از `{` تا `}` کپی کنید.
3. زیرلن را باز کنید و **Import / وارد کردن** را بزنید. اگر آدرس و کلید را جداگانه دارید، با **+** آن‌ها را وارد کنید.
4. پروفایل واردشده را انتخاب کنید، **Connect / اتصال** را بزنید و مجوز VPN اندروید را تأیید کنید.
5. یک سایت را در مرورگر باز کنید. موفق بودن Ping به‌تنهایی به معنی کار کردن مرور وب نیست.

اختیاری: برای تغییر **Split tunnel / تونل تفکیک‌شده** اول اتصال را قطع کنید، سپس برنامه‌هایی را که باید از زیرلن عبور کنند انتخاب کنید. برای فرستادن کانفیگ به فرد مورد اعتماد، از گزینه اشتراک‌گذاری یا خروجی پروفایل استفاده کنید.

### ویندوز، لینوکس و مک

رابط دسکتاپ در مرورگر باز می‌شود و یک پروکسی محلی را کنترل می‌کند. باز شدن این صفحه به‌تنهایی ترافیک مرورگر را از زیرلن عبور نمی‌دهد.

1. در ویندوز فایل `.exe` را اجرا کنید. در لینوکس و مک، نام فایل دانلودشده را در دستورهای زیر جایگزین کنید:

   ```bash
   chmod +x ./YOUR_DOWNLOADED_FILE
   ./YOUR_DOWNLOADED_FILE -gui
   ```

2. با **+** پروفایل بسازید، آدرس Apps Script و کلید برنامه را وارد کنید، سپس ذخیره و انتخاب کنید.
3. در **Tools → Security** گواهی CA زیرلن را بسازید و دانلود کنید؛ این فایل برای مورد اعتماد قرار دادن اتصال رله در مرورگر لازم است. آن را در مرورگری که برای زیرلن استفاده می‌کنید، به‌عنوان مرجع مورد اعتماد سایت‌ها وارد کنید. در فایرفاکس: **Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import**. محل تنظیم گواهی در Chrome و Edge به سیستم‌عامل بستگی دارد؛ از بخش مدیریت گواهی مرورگر استفاده کنید. فقط گواهی ساخته‌شده توسط زیرلن خودتان را مورد اعتماد قرار دهید.
4. پروکسی **HTTP** مرورگر را روی آدرس `127.0.0.1` و پورت `8085` بگذارید. در فایرفاکس استفاده از همین پروکسی برای HTTPS را هم فعال کنید. Chrome و Edge معمولاً از تنظیم پروکسی سیستم‌عامل استفاده می‌کنند و ممکن است برنامه‌های دیگر هم تحت تأثیر قرار بگیرند. پروکسی SOCKS5 هم روی `127.0.0.1:1080` در دسترس است.
5. **Connect** را بزنید و یک سایت را در همان مرورگر باز کنید.

بعد از پایان کار، اتصال را قطع و تنظیم پروکسی مرورگر یا سیستم را خاموش کنید تا مرورگر به پروکسی متوقف‌شده وصل نماند.

برای انتقال کانفیگ به اندروید از **Tools → Mobile Export** استفاده کنید و متن کامل را خصوصی بفرستید.

## حالت مستقیم بدون کانفیگ

این حالت برای سرویس‌های گوگل است و جای رله برای سایت‌های دیگر را نمی‌گیرد. ممکن است برای بعضی محدودیت‌ها کمک کند، اما از همه نوع مسدودسازی عبور نمی‌کند.

- **اندروید:** ورودی Direct/Google را انتخاب کنید، اتصال را بزنید و مجوز VPN را بدهید.
- **دسکتاپ:** گزینه **Direct (Google)** را انتخاب کنید، وصل شوید و پروکسی مرورگر را طبق مراحل بالا تنظیم کنید. برای حالت مستقیم به گواهی CA زیرلن نیاز ندارید.

## اگر وصل نشد

| مشکل | قدم بعدی |
|---|---|
| کانفیگ وارد نمی‌شود | تمام JSON را کپی کنید؛ باید دو قسمت `url` و `key` داشته باشد. |
| خطای Unauthorized یا کلید اشتباه | صاحب کانفیگ باید کلید برنامه را با `AUTH_KEY` در Apps Script تطبیق دهد. |
| دسکتاپ وصل است ولی سایت باز نمی‌شود | تنظیم پروکسی و گواهی مرورگر را بررسی کنید. |
| بعضی سایت‌ها با Cloudflare باز نمی‌شوند | تونل TCP کلادفلر نمی‌تواند به محدوده IP خود Cloudflare وصل شود. پروفایل VPS را امتحان کنید؛ این محدودیت به‌خصوص روی مسیر تونل اندروید اثر دارد. |
| سهمیه گوگل تمام شده | پروفایلی از یک حساب گوگل دیگر را امتحان کنید یا منتظر بازیابی سهمیه بمانید. دیپلوی‌های یک حساب سهمیه مشترک دارند. |
| پاسخ HTML به‌جای JSON یا رله در دسترس نیست | صاحب رله باید دسترسی دیپلوی، نسخه منتشرشده و خطاهای سهمیه را بررسی کند. HTML به‌تنهایی به معنی تمام شدن سهمیه نیست. |
| اندروید دوباره مجوز VPN می‌خواهد | مجوز را بدهید؛ ممکن است VPN دیگری جای زیرلن را گرفته باشد. |

اگر صاحب رله هستید، [فهرست بررسی راه‌اندازی](relay-setup.md#بررسی-قبل-از-اشتراکگذاری) را ببینید؛ در غیر این صورت از صاحب کانفیگ بخواهید رله را بررسی کند. برای [گزارش مشکل](https://github.com/ajavadinezhad/zyrln/issues)، مدل دستگاه، نسخه برنامه، نوع خروجی، متن خطا و مراحل تکرار مشکل را بنویسید. کلیدها و کانفیگ خصوصی را از گزارش حذف کنید.
